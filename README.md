# 他们说我是魔王

**版本：v0.12.1** · 像素风叙事动作游戏 Demo

你扮演被村庄判作魔王的修钟人，在三个夜晚中迎战民兵、成长并面对勇者。村民送出的见闻会影响你的成长方向，也会改变勇者的准备；战斗中的选择将导向不同结局。

## 在线试玩

启用 GitHub Pages 后，将仓库地址替换为 GitHub 提供的 Pages 网址：

`https://<你的用户名>.github.io/<仓库名>/`

本项目是纯静态网页，没有构建步骤和后端服务。先在 GitHub 新建一个公开仓库，打开仓库的 **Add file → Upload files**，把本发布包中的文件和 `assets` 文件夹上传并提交，确保 `index.html` 位于仓库根目录。然后在 **Settings → Pages** 中选择从 `main` 分支的根目录发布。等待 GitHub Pages 显示部署完成后，用生成的网址打开游戏。

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D 或方向键 |
| 瞄准 | 鼠标移动 |
| 炎息 | 按住鼠标左键 |
| 震慑 | Q 或鼠标右键 |
| 冲撞 | 空格 |
| 互动、拦截信件 | 靠近目标后按 E |
| 强化选择 | 1 / 2 / 3，也可点击选项 |
| 暂停、设置与图鉴 | Esc 或页面按钮 |
| 囤火流引爆 | 获得织火领域后按 F |

建议使用电脑上的现代浏览器和键盘、鼠标游玩。手机可以打开页面查看，但当前战斗操作针对键鼠设计。

## 项目特点

- 三夜战斗与勇者决战，包含四种结局
- 每次升级选择强化，火焰、震慑和冲撞形成不同流派
- 放行的战斗见闻同时影响强化方向和勇者备战
- 像素角色、技能动作、受击效果和音效由本地网页资源呈现
- 对话剧情、可互动地点、线索图鉴与地图融入战斗流程
